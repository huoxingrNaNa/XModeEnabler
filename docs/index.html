⚠️ 使用前必读：请搭配散热背夹使用。 本应用只负责让 X 模式策略被触发，它本身不提供任何制冷能力。不接外置散热就长时间开 X 模式， 结果通常是烫手机 + 高温降频，帧率反而不如均衡模式。

它解决什么问题

ColorOS 把 X 模式锁在「原装散热背夹」的私有信号上，第三方散热器再强也触发不了。

关于「游戏助手里不显示 X 模式」

这是官方设计，不是本应用失效，先说清楚免得误判。

事实依据
X 模式入口绑原装背夹助手资源文案：「连接欧加散热背夹后会自动开启 X 模式……开启方式：开启蓝牙并连接散热背夹」
一加 / OPPO 按 设备类（COD） 判定CoolingBackClipOplusFeature.isCoolType(cod, type)：cod ∈ 0x0A04 … 0x0A94（37 个值）且 type == 2（LE）
第三方蓝牙名白名单只服务 realme名单在 assets/sys_cooling_back_clip_whitelist_assets.xml，匹配逻辑在 CoolingBackClipRealmeFeature，一加不会调用
本应用绕过界面直接投递 mode=3助手侧日志可见 chengPerfMode 3、toAppliedMode = 3、showFrameViewVisible switchMode: xMode

社区里能让界面也显示 X 的方案均需 root + LSPosed（如 LuckyTool hook CoolingBackClipFeature 与 oplus.software.general.cooling.back.clip.enable），本项目不采用该路线。

快速开始

一次性配置，之后开机点一下即可。

  1. 安装并启动 Shizuku无线调试方式激活，本应用申请授权时允许。
  2. 安装本应用，打开「启动常驻监控」前台服务会常驻，通知栏出现状态标题。
  3. 把要维持的游戏加入白名单留空则对全部游戏生效；建议只放需要的，避免误判。
  4. 进游戏，等 5～10 秒通知标题变成「X模式生效中」即为成功。
  5. 配好散热机身温度持续 ≥45℃ 说明散热不足，建议退回均衡模式。
